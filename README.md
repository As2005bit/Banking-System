# Banking System

A simple banking system developed using Python, Flask, SQLite, HTML, CSS, and JavaScript.

## Features

- Login
- Create Account
- Deposit
- Withdraw
- Transfer
- Transaction History
- Profile Update

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Run

```bash
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000` in your browser.
